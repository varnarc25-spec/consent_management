# MVP Release Scope

The first usable commercial version should contain:

1. Account and organization management
2. Domain registration and verification
3. Website installation script
4. Consent categories
5. Customizable consent banner
6. Accept, reject and customize actions
7. Consent storage and history
8. Consent withdrawal
9. Manual script and iframe blocking
10. Basic automatic cookie blocking
11. Headless website scanner
12. Cookie detection and categorization
13. Cookie declaration
14. Preference center
15. Google Consent Mode v2
16. Geo-targeted configurations
17. Basic multilingual support
18. Compliance dashboard
19. Consent and scan reports
20. WordPress and GTM installation support

## Related Sprints

Sprints 1–14 and Sprint 16 collectively deliver the MVP scope.
