# Definition of Done

A story is complete only when:

- [ ] Requirements are approved
- [ ] UI and API implementation are complete
- [ ] Permission checks are implemented
- [ ] Unit tests pass
- [ ] Integration tests pass
- [ ] Accessibility checks pass where applicable
- [ ] Security review is complete
- [ ] Audit events are generated
- [ ] Documentation is updated
- [ ] Acceptance criteria are validated
- [ ] The feature works in staging
- [ ] Product owner approval is received
